Refactor the auth module to use OAuth. Keep the existing session API compatible.

The user wants OAuth without breaking the session API. I should keep SessionStore interface unchanged, add an OAuth provider abstraction, and store tokens in the same session table.

Plan

I'll refactor in three layers so existing callers don't change:

  • Provider layer — generic OAuthProvider interface.
  • Session layer — extend SessionStore to accept provider and subject.
  • HTTP layer — add /auth/oauth/:provider callbacks while keeping /auth/session.
src/auth/oauth.ts 
export interface OAuthProvider {
  authorizeUrl(state: string): string
  exchange(code: string): Promise<OAuthClaims>
}

export async function createSessionFromOAuth(
  provider: OAuthProvider,
  code: string,
): Promise<Session> {
  const claims = await provider.exchange(code)
  return sessionStore.create({
    subject: claims.sub,
    provider: claims.iss,
    email: claims.email,
  })
}
