# BUG-012 — Blank gap under the composer

## Symptom (user)

A visible blank band between the composer and the bottom of the screen on mobile.

## Root cause

Bottom safe-area inset was applied twice. The app uses a `100dvh` shell
(main.tsx) + `viewport-fit=cover`, and the chat composer already pads itself with
`env(safe-area-inset-bottom)` (the correct bottom-edge owner). `<body>` ALSO had
`padding-bottom: env(safe-area-inset-bottom)` (index.css), so the inset was
double-counted → a blank gap under the composer on gesture-bar devices. Confirmed
via Playwright that there is no structural gap (composer flush at the bottom when
safe-area = 0), so the gap was purely the duplicated inset.

## Fix

Remove the bottom safe-area padding from `<body>`; keep top/left/right. Edge
components own their insets (the composer keeps its own bottom inset). Verified
on-device.
