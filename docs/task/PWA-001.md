# PWA-001 Make BKD an installable PWA

- **status**: completed
- **priority**: P2
- **owner**: claude (pma)
- **createdAt**: 2026-06-06 13:48

## Description

BKD is positioned as a self-hosted, mobile-first chat tool, but it is not an
installable PWA. Current state:
- `public/manifest.json` is stale (short_name "Kanban", only a single SVG icon,
  no maskable icons) and is **not referenced** from `index.html`.
- No service worker; `vite-plugin-pwa` is not installed.

Goal: ship a real PWA so users can "Add to Home Screen" and run BKD full-screen
like a native app on mobile and desktop.

Acceptance criteria:
- Add `vite-plugin-pwa` with a correct manifest (name/short_name, theme/background
  color matching the app, maskable 192px + 512px icons, `display: standalone`).
- Service worker registered with `autoUpdate`; an in-app "new version" prompt.
- API requests (`/api/*`, SSE `/api/events`, WS) are excluded from SW caching.
- `index.html` references the manifest + apple-touch meta tags.
- Installable on Chrome/Android and iOS Safari (full-screen standalone).

## Completion notes (2026-06-06)

- Added `vite-plugin-pwa` (frontend devDep); configured `VitePWA` in
  `vite.config.ts` (`registerType: 'autoUpdate'`, auto SW registration → seamless
  update, no nag prompt).
- Manifest: name/short_name "BKD", `display: standalone`, theme `#2563eb`,
  background `#09090b`, icons 192 + 512 + maskable-512.
- Icons generated with ImageMagick (gradient + "BK"), since the source is an SVG
  and no SVG→PNG tool with gradient/text support was available:
  `pwa-192x192.png`, `pwa-512x512.png`, `pwa-maskable-512x512.png` (smaller text
  for the maskable safe zone), `apple-touch-icon.png` (180).
- `index.html`: apple-touch-icon, theme-color, apple-mobile-web-app-* meta,
  `viewport-fit=cover`. Removed the stale `public/manifest.json`.
- Workbox: precache static assets; `navigateFallbackDenylist: [/^\/api/]` so the
  SW never hijacks API / SSE / WebSocket routes.
- Build verified: `dist/sw.js` + `manifest.webmanifest` + icons generated (179
  precache entries). Lint clean; vitest unaffected.

Deploy: frontend-only → hot-reloadable on its own, but can ride WT-001's restart
(0.0.190) since that one already needs a graceful-drain restart for migration 0029.
