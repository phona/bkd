# WT-002 Make terminal cwd worktree-aware

- **status**: completed
- **priority**: P1
- **owner**: claude (pma)
- **createdAt**: 2026-06-06 13:48

## Description

Opening the terminal from an issue lands in the wrong directory. The terminal
cwd is hardcoded to `process.env.HOME` (`apps/api/src/routes/terminal.ts:171`),
fully decoupled from the issue's worktree — even though the engine executes in
the correct worktree dir. So users open a shell that is not where the agent is
working.

Current state:
- `POST /api/terminal` takes no body; cwd is `process.env.HOME || '/'`.
- Frontend `TerminalView.createSession()` POSTs with no parameters.
- `terminal-store` has no issue/worktree association.

Goal: terminals opened from an issue context start in that issue's worktree (or
project root when there is no worktree); the global `/terminal` keeps a sane
default.

Acceptance criteria:
- `POST /api/terminal` accepts an optional `cwd`, validated against an allowlist
  (must resolve inside a known project/worktree dir — reject traversal).
- Frontend passes the active issue's worktree path (or project dir) when opening
  the terminal from an issue.
- No issue context → fall back to project root or HOME.
- Mobile + desktop parity.

## Completion notes (2026-06-06)

Backend (`apps/api/src/routes/terminal.ts` + new `terminal-cwd.ts`):
- `POST /api/terminal` accepts optional `{ cwd }`. `resolveTerminalCwd()`
  validates it against an allowlist (ROOT_DIR ∪ WORKTREE_BASE ∪ every
  `projects.directory`) using `realpathSync` on both sides (blocks `..`/symlink
  escapes). Invalid cwd → 400; absent → HOME fallback.

Frontend:
- `terminal-store`: `pendingCwd` + `restartToken` + `openInDir(cwd, fullscreen)`.
- `TerminalView`: `createSession(cwd)` sends the body; `initConnection` consumes
  `pendingCwd` to start a fresh session there; `restartConnection` recreates when
  already open (restartToken).
- `ChatArea`: a terminal button in the issue header opens the terminal in the
  issue's worktree (`useProjectWorktrees`) or the project directory. Desktop +
  mobile (fullscreen on mobile). i18n `chat.openTerminalHere` (en + zh).

Tests: `test/terminal-cwd.test.ts` (6) + `test/terminal-lifecycle.test.ts` cwd
cases (400 invalid / 200 valid). 10/10 green. Lint + typecheck clean.

Deploy: routes/frontend only — engine-core hash unchanged → hot-reloadable
(same zero-downtime path as BUG-004). Not yet packaged/deployed.
