# BUG-008 — Expanded composer toolbar covers the last message (mobile)

## Symptom (user)

On mobile, when scrolled to the bottom and you enter edit mode (tap the input),
the collapsed toolbar expands (taller composer) and covers the last message. The
title/toolbar auto-hide also flickers at the bottom edge.

## Investigation

Reproduced layout via Playwright (system Chrome, mobile viewport): on focus the
composer grows 52px → 106px. In headless the chat re-pins to bottom (gap=0) so it
did NOT cover, but on the real device the expand/keyboard/reflow timing leaves the
last message behind the taller toolbar. Composer is `position: relative` (flex
sibling), so this is a re-pin-timing bug, not an overlay bug.

## Fix

- **Covered-message (this change):** on textarea focus, if the user was near the
  bottom, re-scroll to bottom after the toolbar expands (180ms), so the last
  message stays above the expanded toolbar. Mobile-only effect (toolbar only
  collapses/expands on mobile). Mirrors the post-send auto-scroll.
- **Auto-hide flicker (flap):** separate; the title-auto-hide guards are already
  heavily tuned. Not blind-touched — needs on-device repro (a screen recording)
  before changing.

## Verification

Playwright focus repro (gap stays 0, last content above composer); on-device
verify the message is no longer covered.
