# BUG-010 — Composer doesn't collapse after keyboard dismiss

## Symptom (user)

After the soft keyboard is retracted, the composer keeps its expanded (edit-mode)
style instead of collapsing back to the reading bar.

## Root cause

BUG-008 decoupled the composer collapse from scroll, so it now collapses only on
textarea blur (`mobileCollapsed = isMobile && !isFocused && …`). But on mobile —
iOS especially — dismissing the keyboard (keyboard-down button, swipe-down) does
NOT fire `blur`, so `isFocused` stays true and the composer stays expanded.

## Fix

ChatInput watches `window.visualViewport`: on the keyboard open→close transition
(`innerHeight - vv.height` crosses 120px downward) it blurs the textarea, which
flips `isFocused` false and collapses the composer. Mobile-only; cleaned up on
unmount.

## Verification

lint + tsc + tests; on-device verify the composer collapses when the keyboard is
dismissed by any means.
