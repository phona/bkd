# WT-003 — Branch/workspace visibility + merge-back

Close the create→work→review→land loop for worktrees. Full design in PLAN-030.
(Branch-name / base-branch selection already shipped in WT-001/PLAN-025.)

## Steps

1. **Status glyph** (done): `StatusGlyph` (shape+color, semantic tokens) +
   wire onto kanban cards alongside a teal worktree branch chip — glanceable,
   mobile-visible.
2. **Detail visibility**: surface worktree/branch + status on the issue detail
   header instead of behind a button hidden on mobile.
3. **Merge-back**: a backend endpoint to merge the issue's worktree branch into
   its base (visible conflict reporting, no silent failure) + a "Merge / discard"
   action so landing changes never leaves bkd. (Backend = bun:test-verifiable;
   UI needs manual verification.)

## Verification

Unit test the glyph mapping + merge endpoint (backend); manual verify card/detail
rendering and the merge action.
